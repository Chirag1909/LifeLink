LifeLink

A Blood Donor Finder and Emergency Request Management System

Major Project Title: Full-Stack Web Development Major Project

Architecture: React Front-End • Java + Spring Boot Back-End • JDBC Database

Evaluation Criteria: Front-End, Back-End, Implementation (Integration), and Project Report

1. Abstract & Executive Summary

Timely access to safe blood transfusions is one of the most critical determinants of patient survival during traumatic accidents, complex surgeries, and acute medical emergencies. Conventional blood procurement mechanisms often rely on fragmented telephone trees, manual registry queries, or unverified social media appeals, resulting in critical delays, privacy breaches, and non-compliance with biological donation safety intervals.

LifeLink is an enterprise-grade full-stack web application engineered using React 19 (Vite 8) styled with Tailwind CSS on the front-end, Java 21 and Spring Boot 3.3.5 on the back-end, and a JDBC Database (supporting both H2 persistent storage and MySQL). It automates the matching of verified, available blood donors with emergency hospital requests in real time.

2. Problem Statement & Objectives

2.1 Problem Statement

  • Inefficient Matching: General blood drives do not account for immediate geographic and biological compatibility during emergency trauma cases.
  • Donor Safety Neglect: Lack of automated interval enforcement leads to premature donations, putting donors at risk of anemia or fatigue.
  • Privacy Vulnerability: Publicly broadcasting personal phone numbers on social forums exposes voluntary donors to spam, harassment, and fraud.
  • Lack of Lifecycle Accountability: Emergency requests remain unresolved with no verifiable audit trail of hospital fulfillment or donor contribution history.

2.2 Project Objectives

  • Automate Compatibility Matching: Implement medical ABO and Rh factor rules to pair patients with biologically compatible donors in the same municipality.
  • Enforce Medical Safety: Calculate and track the mandatory 90-day biological rest interval for donors with real-time countdowns.
  • Safeguard User Privacy: Mask donor telephone numbers in public searches and unlock them only upon verified donor consent.
  • Deliver Role-Based Dashboards: Provide tailored, responsive interfaces for Donors, Hospital Requesters, and System Administrators.
  • Provide Verifiable Audit Records: Automatically log completed donation records upon fulfillment and maintain permanent donor histories in the JDBC database.

4.2 90-Day Medical Rest Cooldown Algorithm

To prevent post-donation anemia and comply with clinical guidelines, donor eligibility enforces a strict 90-day cooldown interval:

Elapsed Days = ChronoUnit.DAYS.between(lastDonationDate, LocalDate.now())

Eligible = (isAvailable == true) ∧ (isVerified == true) ∧ (isBlocked == false) ∧ (lastDonationDate is null ∨ Elapsed Days ≥ 90)

When a request is marked Fulfilled, the system writes a new Donation entity and sets lastDonationDate = LocalDate.now(), resetting the donor's 90-day cooldown.

4.3 Two-Stage Contact Privacy Protection

In public searches and preliminary match listings, donor phone numbers are automatically masked (e.g., +1 5*******). Only when an eligible donor accepts an open request does the system reveal their direct contact hotline to the requester.

4.4 Request Lifecycle Automation

Open → Accepted → Fulfilled / Closed / Expired. Requests that exceed their neededBy timestamp automatically transition to Expired.

5. Functional Modules Description

5.1 Front-End Modules

  • Landing & Live Search: Public blood group and city search with exact/compatible match modes and interactive SVG compatibility table.
  • Authentication: Registration with role selection and 1-click evaluation demo login buttons.
  • Donor Dashboard: Live availability toggle, eligibility banner with 90-day countdown, matching emergency feed, and verified donation history.
  • Requester Portal: Emergency request broadcast form, matched donors modal, unlocked donor contact card, and fulfillment action button.
  • Admin Console: Telemetry counters, SVG distribution charts (donors by group, requests by status), user verify/block controls, and request management.

7. Conclusion

LifeLink successfully demonstrates the application of modern full-stack web engineering using React, Java, Spring Boot, and JDBC. By automating biological compatibility matching, safeguarding donor privacy, enforcing medical safety rest intervals, and providing comprehensive administrative governance, the platform delivers an end-to-end solution for urgent blood requisition.
